# /think — Load ideation context

Get ready to brainstorm. Reads the stuck stack, the routing rubric, and the collaboration theory so when Isaac drops a brain-dump or says "what do you think," you're already aligned.

Run after `/boot` or standalone when the conversation shifts to open mode.

## Steps

### 1. Stuck stack

Read `me.md`. Note the top 3 unresolved items and how old they are. If any item is >2 weeks unmoved, flag it — triage cadence says triage or delete.

### 2. Routing rubric

Skim `idea-triage.md` — the 5-axis scoring system (Frame/Task, Compound/One-shot, Reversibility, Blast radius, Tracer-round). 1-5 each, total 25. Routes to: ship (20-25), plan (15-19), spike (10-14), sit (5-9), decline (<5). Know the rubric exists so brain-dumps get scored on the spot.

### 3. Alignment calibration

Read `corrections-log.md` if not already loaded by `/boot`. The 7 corrections are how Isaac actually pushes back — scope-creep, wrong-frame, register-drift. These calibrate how far to push in open mode.

Optionally skim `brainstorm/28_*_collaboration-framework*.md` (BS28) for the deep theory if the session is generative and long.

### Output

```
THINK — [date]
Stuck stack: [N items, oldest: date]
  - [top item 1]
  - [top item 2]  
  - [top item 3]
Flagged for triage: [any >2 weeks]
Rubric loaded. Open mode ready.
```

Then wait for Isaac's direction. Don't start generating ideas unprompted — open mode means listening first.
